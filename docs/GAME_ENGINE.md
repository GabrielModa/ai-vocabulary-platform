# Game engine

## Purpose

Motivate consistent, meaningful practice without distorting mastery or encouraging unhealthy use.

## Boundaries

The game engine owns XP, missions, achievements, streak presentation, collections, cosmetic rewards,
and boss-battle framing. It consumes verified learning events but cannot modify mastery, review
schedules, answers, or entitlements.

## Rules

- Reward effort and meaningful retrieval, not repetitive low-value actions.
- Apply server-authoritative, idempotent reward transactions with auditable reasons.
- Cap exploitable sources and detect abuse without blocking legitimate offline activity.
- Provide streak repair or grace rules that do not require excessive use or payment.
- Avoid chance-based paid rewards, manipulative scarcity, public shaming, or dark patterns.
- Make animations optional and provide reduced-motion equivalents.

## Measurement

Evaluate motivation features against retention, session quality, wellbeing guardrails,
accessibility, and long-term return—not only clicks or time spent.
