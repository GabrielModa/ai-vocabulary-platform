# ADR-053 — OEWN sense-bound examples

## Status

Accepted.

## Context

The application still displays examples generated by the local language model. Those examples can be
generic or semantically disconnected from the verified sense. Open English WordNet 2025 already
includes curated usage examples on many synsets and is distributed under CC BY 4.0.

## Decision

Extract OEWN examples into a compact local index keyed by `senseId` and expose them through a
provider-neutral `ExampleProvider`.

The server requests examples only after a unique lexical sense has been selected. A verified OEWN
example replaces the generated display example, while all returned examples preserve source ID,
version, URL, license, attribution, and retrieval time. Missing or malformed example data fails soft
and leaves the generated example clearly unchanged.

## Alternatives rejected

- Integrate a new sentence corpus first: adds licensing, sense-alignment, and import complexity
  before using data already available in OEWN.
- Ask the LLM to improve the sentence: remains non-deterministic and unverified.
- Match examples by word only: can attach an example to the wrong meaning.
- Commit the full OEWN dataset: unnecessary repository growth.

## Consequences

Study content gains verified, sense-bound context without a new remote dependency. Coverage is
limited because not every OEWN synset has examples. Exercise generation from those examples remains
a separate checkpoint so validation of unique answers is not mixed into source integration.

## Rollback

Remove the example provider, importer, route loader, enrichment metadata, tests, ADR, and Task 053
document. Generated examples continue to work as before.
