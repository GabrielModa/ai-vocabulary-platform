# UX guidelines

## Navigation

Design mobile first for one thumb and one primary action per screen. Preserve a learner's place
across interruptions, app restarts, connectivity changes, and device rotation. Desktop adds space,
not separate concepts.

## Learning flow

- State the task through an example or concise instruction.
- Accept input quickly and tolerate harmless formatting variation.
- Confirm correct reasoning; for errors, identify the misconception and invite retrieval again.
- Reveal hints progressively and record hint level as part of mastery evidence.
- End sessions at a natural boundary and clearly save progress.

## Language and feedback

Use short, respectful, non-judgmental language. Do not shame mistakes, broken streaks, accents, slow
responses, or accessibility adaptations. Pronunciation feedback communicates uncertainty and offers
actionable practice rather than declaring an accent wrong.

## States

Every screen specifies empty, loading, partial, offline, success, recoverable error, and terminal
error behavior. Optimistic UI is used only when reconciliation cannot mislead the learner.

## Accessibility and localization

Support keyboard-only and screen-reader use, captions and transcripts, non-audio alternatives,
reduced motion, large text, and bidirectional-safe layouts. UI copy is externalized and designed for
pluralization and text expansion.
