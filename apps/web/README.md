# Learner web application

Next.js App Router foundation for the responsive learner experience.

```bash
pnpm --filter @vocabulary/web dev
pnpm --filter @vocabulary/web test
pnpm --filter @vocabulary/web build
```

The current route is intentionally a semantic foundation status, not a product or marketing screen.
It establishes English metadata, dark-first responsive styling, visible focus, reduced-motion
support, safe error states, and validated public configuration.
