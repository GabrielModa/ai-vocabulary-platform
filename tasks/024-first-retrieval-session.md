# 024 — Add first retrieval training session

## Goal

Run a deterministic one-challenge-at-a-time retrieval session with immediate useful feedback.

## Requirements

- Require a non-empty validated challenge set.
- Record one immutable attempt per answer and never equate score with mastery.
- Normalize answers, reveal the expected answer after an attempt, and complete deterministically.
