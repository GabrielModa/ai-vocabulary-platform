# Task 080 — Exercise Capability Planner

## Objective

Derive supported exercise strategies from resolved lexical evidence.

## Acceptance criteria

- A verified definition enables definition-based strategies.
- Verified cloze requires an official example containing the target as a complete lexical token.
- Unrelated examples and morphological supersets do not enable cloze.
- Pronunciation evidence enables audio recognition.
- Missing evidence produces explicit reason codes.
- Plans are deterministic and immutable.
- No API, UI, database, draft, or session behavior changes.
- Focused tests, typecheck, lint, build, and formatting pass.
