# Task 083 — Definition Choice Publishing

## Objective

Orchestrate capability planning, distractor selection, and composition into one published exercise.

## Acceptance criteria

- A compatible resolved knowledge pool produces a published definition-choice exercise.
- The publication includes stable publication and exercise IDs.
- Exactly three selected distractor knowledge IDs are recorded.
- Target provenance is retained.
- Insufficient compatible pools return a structured failure.
- Repeated input produces identical output.
- Results are immutable.
- No API, UI, database, draft, or study-session behavior changes.
- Focused tests, typecheck, lint, build, and formatting pass.
